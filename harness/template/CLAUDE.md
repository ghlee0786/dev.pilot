# Claude Code 전용

- 요청한 범위만 한다. 요청 밖의 리팩터 · 정리 · 기능 추가로 넓히지 않는다.
- 서로 독립적인 일(조사 · 시나리오 시험 · 검토 · 서로 다른 파일의 작업)은 서브에이전트로 나눠 한 메시지에서 동시에 띄운다. 같은 파일을 여러 에이전트가 고치게 나누지 않는다 — 그렇게 나눠야 하면 각자 레인(`start`).
- 판정은 저장소 테스트 명령의 종료 코드다 — 에이전트의 의견으로 판정하지 않는다. 시험을 쓰고 돌리는 서브에이전트는 된다(그 시험이 판정이 된다).
- 무언가를 만들거나 고쳐 달라는 큰 요청은 `harness` 스킬을 따른다.
